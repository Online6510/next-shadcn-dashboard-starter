# Хөгжүүлэлт ба шалгалтын тэмдэглэл

1. Эх загварын `README`, `AGENTS.md`, Bun lockfile болон App Router бүтцийг шалгав. Өгөгдөл, хуудсын логикийг зөвшөөрөл шаардах Clerk болон Sentry-ээс салгахын тулд cleanup скриптийн жагсаалт, dry run ашиглав. Хуучин демо хуудсуудыг route-уудаас авсан.
2. Монгол хэлтэй нүүр хуудас, хайлт, онцлох газрын гүйлгэдэг цэс, дэлгэрэнгүй хуудас хийв. ImageGen дүрслэлийг локал WebP болгож, кирилл фонтын файлуудыг npm багцаас локал ачаалдаг болгов.
3. SQLite хадгалалт, Zod шалгалт, саналын дүрэм, аяллын форм, өдрийн хөтөлбөр, координатын зураг, зардал болон дурсамжийн дэвтрийг холбов. Өгөгдлийн сан анх үүсэхэд Хөвсгөлийн аяллыг нэг удаа нэмдэг.
4. Chromium дээр 1440×900, 390×844 хэмжээнд нүүр, газар, аяллын хөтөлбөр, дурсамж, саналын хуудсыг шалгав. Дэлгэцийн зургууд [screenshots](screenshots/) дотор бий. Гар утасны цэс болон товчийн хэмжээг тохируулж, формын шошгыг талбартай шууд холбов.

## Баталгаажуулсан нь

| Үйлдэл | Үр дүн |
| --- | --- |
| `bun install --frozen-lockfile` | Lockfile-оос суулгав |
| `bun run typecheck` | Амжилттай |
| `bun test` | 4 тест амжилттай |
| `bun run lint` | Алдаагүй, эх загварын бүрэлдэхүүнүүдэд 10 анхааруулга |
| `bun run build` | Амжилттай. Node 22 SQLite-ийн туршилтын API-н мэдэгдэл гарсан |
| Chromium ажиллагааны шалгалт | Газрын хайлт, шүүлт, гүйлгэдэг онцлох хэсэг, аялал нэмэх/засах/устгах, 3 зогсоол нэмэх ба эрэмбэлэх, газрын цэг сонгох, зардал бүртгэх/засах/устгах, дурсамж нэмэх/засах/устгах, Escape-аар зураг хаах, дүрэмт саналыг хадгалах үйлдлүүд амжилттай |
| SQLite хадгалалт | Шалгалтын аялал, хөтөлбөр, зардал, дурсамжийг хуудсыг дахин ачаалахад сэргээв. Тусдаа production процесс SQLite-ээс өмнө хадгалсан аяллыг уншив |

Гэрэл зургийн оронд Монголын газруудаас сэдэвлэсэн дүрслэл ашиглав. Газрын зураг нь офлайн координатын бүдүүвч бөгөөд замын бодит чиглэл тооцоолохгүй. Дурсамжийн зураг холбоосоор ордог.

## V2

- Эхлээд V1-ийн 4 тест, frozen install, TypeScript, lint, production build-ийг шалгав. Хадгалагдсан SQLite санд нэг аялал байсан. Браузерын засах/устгах шалгалтад тусдаа өгөгдлийн сан ашиглав.
- Хуучин дэвтрийн хоосон зай ихтэй гарчгийг нүүр зурагтай болгож, огноогоор бүлэглэсэн цомог, хэвлэх горим, файл оруулах үйлдэл нэмэв. V1-ийн зурагны холбоосуудыг хэвээр уншдаг.
- Leaflet зураг, шүүлт, өдрийн дараалал, төсөв, саналын хөтөлбөрийн өөрчлөлтийг холбов. Газрын каталоги дахь зургаан шинэ нуурын байршил, эргийн дүрсийг Natural Earth өгөгдлөөс авав.
- Браузерын демо давтах үед файл шинээр сонголгүй засахад хоосон file input ирдэг болон төсөв хадгалсны дараа утасны хэсэг буруу сонгогддог асуудлууд илэрсэн. Файлыг ялгах, өөрчлөлттэй хуудсыг шинэчлэх, идэвхтэй хэсгийг URL-д дамжуулах замаар засаж дахин шалгав.
