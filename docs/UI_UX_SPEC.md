# Wanderly V2 харагдац

Нүүр хуудасны ой, усны зураг дээрх цайвар гарчиг болон хоёр товч нь аялал үүсгэх, газар сонгох үндсэн замууд. Каталог нь гэрэл зурагтай оршил, шүүлт, онцлох газруудтай. Байгалийн зураглалын ард бичвэрийн өнгө ялгарахын тулд зүүн болон доод хэсэгт бараан давхарга тавьсан.

Дэвтэр нь аяллын нүүр, хугацаа, дурсамжийн тоогоор эхэлнэ. Цомогт өдөр бүр тусдаа бүлэг бөгөөд зураг, бичвэр ээлжилнэ. Он дарааллын харагдацад бичвэрт илүү зай өгнө. Хэвлэх үед засварын удирдлагууд алга болно.

Десктопт өдрүүд, зогсоол, зураг зэрэгцэнэ. Утасны дэлгэцэд хөтөлбөр, газрын зураг, төсвийг тус тусад нь сонгоно. Төсвөө засахад тухайн өдөр болон төсвийн хэсэг хадгалагдана. Зогсоолын дараалал солих товчнууд нь гар болон мэдрэгчтэй дэлгэцэд ажиллана. Навигацын болон зургийн цонх нь native dialog ашиглаж Escape-аар хаагдана.

V1 болон V2-г харьцуулахын тулд docs/screenshots/ ба docs/screenshots/v2/ дахь ижил нэртэй зургуудыг нээнэ.
