| Хэсэг | Хийж болох зүйл |
| --- | --- |
| Нүүр | Газрууд, шинэ аялал, Хөвсгөлийн жишээ аялал болон дурсамж руу очих |
| Газрууд | Онцлох газруудыг гүйлгэж үзэх, Монголын 16 газрыг нэр, шошго, аймаг, төрлөөр хайх, дэлгэрэнгүй мэдээлэл үзэх, шинэ эсвэл байгаа аяллын өдөрт нэмэх |
| Аялал | Нэр, эхлэх ба дуусах огноо, аялагчдын тоо, төсөв, нүүр зураг сонгох, мэдээллээ засах, баталгаажуулж устгах |
| Хөтөлбөр | 30 хүртэл хоногийн өдрүүдээс сонгох, зогсоолын цаг, хугацаа, тэмдэглэл, зардлын тооцоог хадгалах, чирэх буюу товчоор эрэмбэлэх, өдрөөр шилжүүлэх, дарааллыг солих, устгах |
| Газрын зураг | Координатад суурилсан товшдог цэгүүд, Монголын тойм ба өдрийн ойртуулсан харагдац, цэг болон хөтөлбөрийн холбоотой сонголт, Leaflet суурь зураг, сүлжээ тасрахад офлайн зураг |
| Төсөв | Зардлын таван ангилал, нэмэх, засах, устгах, үлдэгдэл эсвэл хэтрэлтийг тооцох, төлөвлөсөн зардлыг тусад нь харуулах |
| Ухаалаг санал | 1–7 хоног, төсөв, аймаг, хэмнэл, сонирхлоор дүрэмт хөтөлбөр тооцоолж, засаж болох аялал болгон хадгалах |
| Дурсамж | Өдөр, газар, түүх, сэтгэл хөдлөл, зургийн холбоос болон 6 хүртэл файл бүхий тэмдэглэл үүсгэх, засах, устгах, он дарааллаар үзэх, зураг томруулах, суман товчоор шилжих, цомог/он дараалал сонгох, хэвлэх |

Аялал, зогсоол, бодит зардал, дурсамж SQLite-д хадгалагдана. Жишээ аялал өгөгдлийн сан бүрд нэг удаа үүснэ.
