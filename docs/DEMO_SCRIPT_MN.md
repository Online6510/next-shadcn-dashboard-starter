# Wanderly-г 2–3 минутад танилцуулах

1. **0:00–0:25.** Нүүр хуудсыг нээнэ. “Wanderly бол Монголд аялах газраа сонгож, өдрүүдээ төлөвлөөд, дараа нь дурсамжаа хадгалах апп” гэж эхэлнэ. **Газруудыг судлах** дээр дарж, “Хөвсгөл” гэж хайна. **Байгаль** төрлийг сонгоод Хөвсгөл нуурыг нээнэ.
2. **0:25–0:55.** **Шинэ аялалд нэмэх** дээр дарна. “Миний Хөвсгөл аялал” гэсэн нэр, дараалсан гурван өдөр, хоёр аялагч, 1,500,000 ₮ төсөв оруулна. Урьдчилж сонгогдсон Хөвсгөл нуурыг эхний өдрийн зогсоол болгон нэмнэ. Зогсоол дээр дарахад газрын зургийн цэг идэвхжихийг харуулна.
3. **0:55–1:25.** **Төсөв** хэсэгт орж **Зардал нэмэх** дээр дарна. Хоолны 120,000 ₮ зардлыг оруулаад үлдэгдэл 1,380,000 ₮ болсныг заана. Хуудсаа дахин ачаалж, мэдээлэл хэвээр байгааг харуулна.
4. **1:25–2:15.** Нүүр хуудас руу буцаж **Жишээ аялал үзэх** дээр дарна. Өдрүүдийг сольж, **Дурсамжийн дэвтэр** дээр дарна. Гурван тэмдэглэлээс нэг зургийг томруулж, Escape товчоор хаана. Энэ хэсэгт шинэ түүх нэмж болдгийг үзүүлнэ.

## Техникийн асуулт, хариулт

- **Refresh хийхэд мэдээлэл хаанаас ирдэг вэ?** Аялал тус бүр серверийн SQLite файлын нэг баримт. Сервер хуудас руу дахин ороход тэр бичлэгийг уншдаг.
- **Тооцоолсон болон төлсөн зардлын ялгаа юу вэ?** Зогсоолын дүн нь тооцоо. Төсвийн үлдэгдлээс зөвхөн бодит зардлыг хасна.
- **Цэгүүд яаж байрладаг вэ?** Газрын каталогоос өргөрөг, уртрагыг авч вектор бүдүүвч дээр байрлуулна. Цэг дээр дарахад ижил ID-тай зогсоол тодорно.
- **Демо серверийг нийтэд тавьж болох уу?** Нийтийн ашиглалтад хэрэглэгчийн бүртгэл, өгөгдөл тусгаарлалт, нөөцлөлт хэрэгтэй.
